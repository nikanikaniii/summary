# План автоматизации тестирования: сценарий записи на курс «Инженер по тестированию» в Нетологии

## А. Сценарии перехода на страницу курса.

1-2. **Сценарий 1: Переход через блок на главной странице.**
Предусловия: Открыта главная страница сайта Нетологии.

   1. *Вариант А:*
   - Выбрать категорию **«Программирование»**.
   - Найти в открывшемся списке курс **«Инженер по тестированию»** и перейти на его страницу.

   - Выбрать категорию **«Программирование»**.
   - В строку "Поиск по каталогу" ввести запрос "Инженер по тестированию" и нажать Enter.
   - Среди результатов поиска найти "Инженер по тестированию: расширенный курс" и кликнуть по нему.
   - Пролистать страницу курса в самый низ до блока с формой записи.

   - **Ожидаемый результат:** Открыта страница "Инженер по тестированию", на экране отображается форма "Запишитесь или получите консультацию" с полями ввода "Имя" и "Телефон", а также с активными кнопками "Записаться" и "Получить консультацию".

## Б. Заполнение и отправка формы записи на курс. Позитивные и негативные сценарии.
Предусловия: Открыта страница курса "Инженер по тестированию".

1. **Позитивный сценарий: Заполнение формы записи на курс валидными данными.**
   - Перейти к форме «Запишитесь или получите консультацию» на странице профессии
   - Заполнить поле **«Имя»** (например, *Иван*).
   - Заполнить поле **«Телефон»** (валидный формат номера с кодом страны +7. Например: +7(900)123-45-67).
   - Нажать на кнопку **«Записаться»**.
  
   - **Ожидаемый результат:** Все поля формы заполнены введенными валидными данными, сообщения об ошибках валидации отсутствуют, кнопка "Записаться" активна и доступна для нажатия. После нажатия кнопки "Записаться" происходит успешная отправка формы.

2. **Негативный сценарий 1: Отправка формы записи на курс с пустыми полями.**
   - Перейти к форме «Запишитесь или получите консультацию».
   - Оставить поля пустыми.
   - Нажать на кнопку **«Записаться»**.

   - **Ожидаемый результат:** Кнопка "Записаться" активна. При нажатии на кнопку форма не отправляется. Под полями "Имя" и "Телефон" отображаются сообщения об ошибке: "Обязательное поле".

3. **Негативный сценарий 2: Ввод невалидных данных в поле "Номер телефона".**
   - Перейти к форме «Запишитесь или получите консультацию».
   - Заполнить поле "Имя" валидным значением (например, Иван).
   - Ввести в поле "Телефон" неполный номер (Например, +7(900)123-45-6_)
   - Нажать на кнопку **«Записаться»**.

   - **Ожидаемый результат:** Кнопка "Записаться" активна. При нажатии на кнопку форма не отправляется. Под полем "Телефон" отображается сообщение об ошибке: "Введите корректный номер телефона".

4. **Негативный сценарий 3: Ввод цифр в поле "Имя".**
   - Перейти к форме «Запишитесь или получите консультацию».
   - Ввести в поле "Имя" цифры (например, 123)
   - Ввести в поле "Телефон" валидные данные (Например, +7(900)123-45-67)
   - Нажать на кнопку **«Записаться»**.

   - **Ожидаемый результат:** Кнопка "Записаться" активна. При нажатии на кнопку форма не отправляется. Под полем "Имя" отображается сообщение об ошибке: "Должно состоять из букв".
  
5. **Негативный сценарий 4: Ввод спецсимволов в поле "Имя".**
   - Перейти к форме «Запишитесь или получите консультацию».
   - Ввести в поле "Имя" спецсимволы (например, @@@)
   - Ввести в поле "Телефон" валидные данные (Например, +7(900)123-45-67 ).
   - Нажать на кнопку **«Записаться»**.

   - **Ожидаемый результат:** Кнопка "Записаться" активна. При нажатии на кнопку форма не отправляется. Под полем "Имя" отображается сообщение об ошибке: "Должно состоять из букв".

6. **Негативный сценарий 4: Граничные значения. Ввод менее двух символов в поле "Имя".**
   - Перейти к форме «Запишитесь или получите консультацию».
   - Ввести в поле "Имя" один символ букв кириллицы (например, ю)
   - Ввести в поле "Телефон" валидные данные (Например, +7(900)123-45-67 ).
   - Нажать на кнопку **«Записаться»**.

   - **Ожидаемый результат:** Кнопка "Записаться" активна. При нажатии на кнопку форма не отправляется. Под полем "Имя" отображается сообщение об ошибке: "Должно быть не короче 2 символов".

## Блок 2. Перечень используемых инструментов с обоснованием выбора
* **Java (JDK 11+)** — основной язык разработки автотестов;
* **IntelliJ IDEA** — среда разработки.
* **Gradle** — современная система автоматической сборки проектов.
* **Selenide (на базе Selenium WebDriver)** — фреймворк для автоматизации действий в браузере.
* **JUnit 5** — фреймворк для написания и запуска тестов, организации предусловий (`@BeforeEach`) и проверок (`Assertions`).
* **Allure Framework** — инструмент для формирования подробных и наглядных отчетов о прохождении тестов со скриншотами в случае падения.

## Блок 3. Перечень необходимых разрешений, данных и доступов
* **Разрешения:** Прямое тестирование с отправкой реальных форм на сайте `netology.ru` (запрещено условиями задачи :) )
* **Тестовые данные:**
  - Валидное имя: `Иван`
  - Валидный номер телефона: `900-123-45-67` (подставляется после кода `+7`)
  - Валидный email: `email@example.com`
  - Набор невалидных строк для проверки масок ввода и валидации (пустые строки, спецсимволы, некорректный формат почты).
* **Доступы:** Специальные учетные записи, пароли или VPN не требуются, так как тестируемые разделы находятся в открытом доступе.

## 4. Перечень и описание возможных рисков при автоматизации
1. **Изменение верстки и локаторов на сайте:** Изменение названий классов, ID или расположения кнопок.
2. **Защита от автоматизированного трафика (Anti-bot / Captcha):** При частых запусках автотестов сервер может заблокировать IP-адрес или показать капчу, приняв тестовый браузер за бота.
3. **Риск случайной отправки лида:** При случайном изменении логики теста или клике по кнопке «Записаться» в отдел продаж Нетологии уйдет фейковая заявка.
